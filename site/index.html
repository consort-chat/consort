Consort updates

This host serves one file: the update manifest an installed Consort polls to find out whether a newer release exists. It is at updater/latest.json.

The installers themselves live on the release pages. Consort is a desktop Matrix client with voice; the repository has the source, the packages and what it can and cannot do yet.

Linux packages are updated by your package manager rather than from inside Consort, so nothing here applies to them.
